# 🛒 FreshCart – E-Commerce Web Application

FreshCart is a responsive e-commerce web application built using **Node.js**, **Express.js**, **EJS**, **MySQL**, **HTML**, **CSS**, and **JavaScript**. It provides a seamless online shopping experience with secure user authentication, product browsing, shopping cart management, and order processing.

---

## 🚀 Features

- 👤 User Registration & Login
- 🔒 Secure Password Hashing using bcrypt
- 🔑 Session-Based Authentication
- 🛍️ Browse Products
- 📂 Product Categories
- 🔍 Product Search
- 🛒 Add to Cart
- ❌ Remove from Cart
- 💰 Shopping Cart Total Calculation
- 💳 Checkout & Order Processing
- ✅ Order Success Page
- 👤 User Account Dashboard
- 📱 Fully Responsive Design (Desktop, Tablet & Mobile)

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/CodeAlpha_FreshCart.git
```

### Open the project folder

```bash
cd CodeAlpha_FreshCart
```

### Install dependencies

```bash
npm install
```

### Configure MySQL

Create a MySQL database and update your database credentials in **app.js**.

### Start the application

```bash
node app.js
```

Open your browser and visit:

```
http://localhost:3000
```
